Case study 03

Automated AWS EC2 Deployment with Docker, Nginx and CI/CD

Role: DevOps Specialist

AWS EC2DockerNginxGitHub ActionsLet's EncryptUbuntu

A Node.js app was released to production by hand, which was slow and caused downtime. I replaced that with a fully automated pipeline on AWS EC2.

What I delivered

  • ✓Provisioned and hardened the EC2 server
  • ✓Containerised the app with Docker Compose
  • ✓Nginx configured as a reverse proxy, with a custom domain via Cloudflare
  • ✓Auto-renewing Let's Encrypt SSL
  • ✓GitHub Actions workflow: every push to main builds and deploys automatically

Pipeline

Code push→GitHub→GitHub Actions→AWS EC2→Docker→Nginx→HTTPS live
Result: Deploy time dropped from about 30 minutes of manual work to about 90 seconds, with zero downtime, instant rollback and HTTPS.
