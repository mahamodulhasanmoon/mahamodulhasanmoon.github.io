Case study 03

Automated AWS EC2 Deployment with CI/CD

Role: DevOps Specialist

AWS EC2DockerNginxGitHub ActionsCloudflareLet's Encrypt

The problem

A Node.js app was released by hand. Each release took around 30 minutes and caused downtime.

What I delivered

  • Provisioned and hardened the EC2 server
  • Containerised the app with Docker Compose
  • Nginx reverse proxy with a custom domain through Cloudflare
  • Auto-renewing Let's Encrypt SSL
  • GitHub Actions: every push to main builds and deploys

Result

Deploy time cut from about 30 minutes to about 90 seconds, with zero downtime, instant rollback and HTTPS.
